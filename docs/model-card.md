## 1. 一句话

给定既有汽轮机在 100 % 工况下四台换热器（过热器 / 蒸发段 / 省煤器 / 再热器）的汽水
参数，算出一套"高温气冷堆 + 熔盐双罐储热"方案的堆模块数、盐量、储罐、换热面积与净电。

## 2. 控制方程与实现

| 环节 | 方程 / 做法 | 实现 |
|---|---|---|
| 四段热负荷 | `Q = m·Δh`，焓由 CoolProp `(p, T)` 求 | `steam_side.py` |
| 亚临界分段 | 省煤器出口 = `T_sat(p_drum) − 过冷度`；蒸发段到饱和汽 | `_duties_subcritical` |
| 超临界分段 | 省煤器出口、水冷壁出口由业主给定；拟临界温度取 `cp` 峰值（1 K 扫描 350–460 °C） | `_duties_once_through`、`properties.pseudo_critical_t` |
| 换热能力 | `kA = ∫dQ/ΔT`，沿程 60 段积分 | `thermal.section_integrated` |
| 盐侧反解 | 内层对冷罐温度二分（使沿程最小端差 = 设计值），外层对主支路份额二分（使主/再热支路同时达标） | `salt_side._bisect_cold` / `_solve_split` |
| 储热定容 | `容量 = |Q_net| × hours`；盐量 `= 容量 / (cp̄·ΔT)` | `salt_side.size_storage` |
| 氦回路 | 风机等熵压缩、堆芯能量平衡反解流量、`Q_IHX = Q_core + P_circ` | `reactor.py` |
| 净电 | `毛电 − 汽机岛辅机 − 氦风机电耗 − 盐泵电耗`，改造前后同口径 | `design.py` |
| 变工况 | 滑压 `p/p0=(m/m0)^k` + 级组效率修正表 + 给水温度表，反解主蒸汽流量 | `offdesign.py` |

## 3. 假设

1. **汽轮机是黑盒**：只以四台换热器的汽水参数为边界；不校验通流能力、末级湿度、胀差。
2. **热耦合按给定热负荷传递**：换热面积用于校核可行性与估算外形，不反算换热量。
3. **盐侧是两条开式回路**（充热 / 放热）；稳态下两罐流量差即储罐吞吐。
4. **蒸汽发生器等效为四段换热器**；不建模减温喷水（喷水量应并入给水流量）。
5. **储罐完全混合、绝热**，不含斜温层、散热与液位约束。
6. **U 值为经验值**（过热/再热 800–1200、蒸发 1500–2500、省煤 1000–1500 W/m²K），
   面积只用于量级判断。
7. **超临界方案依赖新型硝酸盐**：物性按太阳盐拟合，分解温度取 650 °C（**中试假设**）。
   这是"600 °C 主蒸汽能否成立"的唯一支点，必须在对外材料中标注。
8. 不含经济性。

## 6. 已知限制

- 不能预测变工况下的真实通流行为（抽汽压力、末级湿度、胀差）。
- 不能用于换热器选型（无管程/壳程几何、无污垢系数）。
- 不能判断材料可行性（超超临界的高温材料、盐的腐蚀与长期稳定性）。
- 不能算投资与收益。
- 输入缺失时会用典型值补齐——**这些补齐项必须被业主确认**，否则结论只代表"典型机组"。
